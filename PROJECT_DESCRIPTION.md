# EP (Energy Platform)

Веб-платформа для управления реферальной системой и энергетическими проектами с продуманной системой монетизации и пакетов.

## 🚀 Основная логика проекта (Паки и Доступы)

Проект работает по системе **Freemium** с тремя основными уровнями доступа (пакетами):

### 1. Бесплатный доступ (Без пакета / Starter)
*По умолчанию для всех новых пользователей.*
- **Статистика:** ❌ Ограничена (размыта). Пользователь не видит детальной статистики.
- **Команда:** ❌ Ограничена. Раздел "Команда" заблокирован.
- **Рефералы:** ❌ **Нет начислений.** Пользователь не получает поинты за активность своих рефералов.

### 2. Start Pack (Пакет "Popular")
*Базовый платный пакет.*
- **Статистика:** ✅ Полный доступ. Открывается доступ к статистике профиля и **личным рефералам**.
- **Команда:** ✅ Полный доступ к дереву рефералов.
- **Рефералы:** 💰 **Стандартные начисления.** Пользователь получает стандартные бонусы (Level 1, 2, 3) от своей структуры.

### 3. Standard Pack (Пакет "Business")
*Продвинутый пакет для партнеров.*
- **Статистика:** ✅ Полный доступ ко всем метрикам.
- **Бонусы:** 📈 **Повышенные начисления (+50%).** При получении бонусов от рефералов, система начисляет **дополнительный бонус**.
  > *Логика:* Если стандартный бонус 20 поинтов, владелец Standard Pack получит 30 поинтов.

### 4. Premium Pack (Пакет "Premium")
*Максимальный пакет.*
- **Бонусы:** 🚀 **Удвоенные начисления (x2).** Максимальная выгода от реферальной сети.

## 🛠 Технологический стек

- **Frontend**: Next.js 14 (App Router), React, TypeScript
- **Styling**: TailwindCSS, Lucide Icons
- **Backend**: Next.js API Routes (Serverless functions)
- **Database**: MySQL (с использованием пула соединений)
- **Auth**: JWT токены (Secure Cookies)

## 📦 Функционал

### Для Пользователя
- **Регистрация/Вход:** С поддержкой реферальных кодов.
- **Дашборд:** Просмотр статистики (зависит от пакета).
- **Магазин:** Обмен заработанных поинтов.
- **Партнерская программа:** Ссылка для приглашения, отслеживание команды.

### Для Администратора
- **Управление пользователями:**
  - Одобрение регистраций.
  - **Выдача Пакетов:** Ручное изменение уровня пакета (Starter -> Premium) через выпадающий список.
- **Управление проектами:** Модерация заявок (Одобрить/Отклонить).
- **Аналитика:** Глобальная статистика по всем пользователям.

## 🎨 Дизайн и "Интеллектуальная Формула"

Проект использует современный подход к UI/UX, названный **"Intelligent Formula Design"**, который фокусируется на конверсии и автоматизации сбора данных.

### 🏠 Главная страница (Sales Funnel)
Дизайн главной страницы построен вокруг **"60-секундного конфигуратора"** — интерактивного пошагового опросника.

- **Wizard-интерфейс:** Пошаговая форма (Тип крыши -> Потребление -> Контакты) снижает когнитивную нагрузку и повышает конверсию по сравнению с обычными формами.
- **Визуальная иерархия:** Градиенты (Blue to Indigo) и "стеклянные" эффекты (Blur) управляют вниманием пользователя, акцентируя его на кнопках действия.
- **Психология выбора:** Блок тарифов подсвечивает "Популярный" вариант, облегчая принятие решения.

### 🤝 Страница Партнеров (B2B Trust)
Дизайн партнерской страницы строг и ориентирован на бизнес.

- **Структура преимуществ:** Три ключевых фактора (Бонусы, Аналитика, Поддержка) вынесены в крупные карточки для быстрого сканирования.
- **Социальное доказательство:** Акцент на прозрачности и высоких комиссионных формирует доверие.
- **Единая экосистема:** Визуальный код (шрифты, скругления, цвета) совпадает с основным сайтом, создавая ощущение целостного продукта.
